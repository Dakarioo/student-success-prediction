# Fonctionnement du code

Ce dossier rassemble les documents qui **expliquent le fonctionnement interne** des programmes
Python du projet : ce que fait chaque fichier, comment, et pourquoi. Ils servent à comprendre,
relire et défendre le code en soutenance (évaluation individuelle).

| Document | Contenu |
|---|---|
| [programmes_python.md](programmes_python.md) | Fonctionnement de tous les programmes Python de l'audit de qualité (mission 1) : modules, détecteurs, sorties, tests, notions statistiques |

Les autres documents de `docs/` répondent à d'autres questions :

- [`data_quality_audit.md`](../data_quality_audit.md) : **utiliser** l'audit (commandes, options, fichiers produits) ;
- [`audit_rules_catalog.md`](../audit_rules_catalog.md) : **liste** des règles d'audit (généré automatiquement) ;
- [`methodology.md`](../methodology.md) : protocole scientifique de la SAÉ.

Convention : un document par mission ou par grand ensemble de code, mis à jour dans la même
Pull Request que le code qu'il décrit.
