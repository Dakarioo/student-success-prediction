# Ressources pédagogiques

Ce dossier contient localement les documents officiels de la SAÉ, **non versionnés** car leur
redistribution n'est pas autorisée à ce jour :

| Fichier | Contenu |
|---|---|
| `SAE5_03.pdf` | Sujet de la SAÉ 5.03 : contexte, six missions, livrables, modalités d'évaluation |

Récupération : télécharger les deux fichiers depuis l'espace Moodle de la SAÉ et les placer ici.
La version Markdown du dictionnaire, enrichie pour le projet, est [`../data_dictionary.md`](../data_dictionary.md).
